# Install Ubuntu Server 26.04 LTS in VMWare Workstaion Pro
**Date:** 2026-11-19-20 **Phase:** 1 **Time Spent:** 4 h

# The Goal
Download 26.04 ISO from the Ubuntu website and get it installed and up to date. Then install git and add the lab repositry to the VM and test it.

# Enviroment
VMWare Workstation Pro, Ubuntu Server 26.04 LTS, 4 vCPU / 8GB RAM

# Steps
1. I downloaded the ISO.
2. I created the VM in Workstation Pro.
3. I got the VM installed and booted up into the terminal.
4. I did the following commands.
        -sudo apt update
        -sudo apt full-upgrade
        -sudo apt install git
        -git config --global user.name "My Name"
        -git config --global user.email "MyEmail@example.com"
        -ssh-keygen -t ed25519 -C "MyEmail@example.com"
        -cat ~/.ssh/id
5. I then add the repo in github and added the SSH key.
6. I then tested it and found out it didnt work. In the learn section I will explain more. 
7. I then created a script to make notes that create a template .md doc that I can push to github.
